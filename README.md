# 📊 Sales Dashboard - Power BI

## 📌 Project Overview
This Power BI Sales Dashboard provides an interactive analysis of sales performance. It helps users monitor key business metrics and identify sales trends through dynamic visualizations.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## 📈 Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Interactive Slicers
